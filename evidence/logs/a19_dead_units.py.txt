==============================================================================
A19.1  the dead-unit move: exactly free, and not in Gamma
==============================================================================

max|df| is over 2000 held-out inputs.  A gauge move is free to
1e-15 (rounding); this one should be free to 0 (the unit is off).

 seed  kill cost (own x)   payload max|df|  in Gamma?
--------------------------------------------------------
    0             1.0256         0.000e+00      False
    1             0.9611         0.000e+00      False
    2             1.0332         0.000e+00      False
    3             1.0149         0.000e+00      False
    4             1.0291         0.000e+00      False
    5             1.0503         0.000e+00      False
    6             1.0707         0.000e+00      False
    7             1.1017         0.000e+00      False

kill cost to the adversary's own error: median 1.0312x  max 1.1017x
payload max|df|: max 0.000e+00 over 8 seeds

Exactly zero, not 1e-16: the payload never reaches the output,
because a dead ReLU is off on every input.  And the incoming row is
bit-identical while the outgoing column changed, which no element of
Gamma can do.  So this is a function-preserving move outside Gamma.
Killing a unit costs the adversary a few percent of its own error,
which is the price of entry; nothing in the harness trains into it.

==============================================================================
A19.2  M4 in isolation is an amplifier, not a blind spot
==============================================================================

canon sets a_j = 1/||(W1_j, b1_j)||, which for a dead unit is
~1/|b1_j|, and multiplies the outgoing column by 1/a_j = |b1_j|.
The adversary chooses |b1_j|, so it chooses the amplification.
The mechanism to verify is the ACTIVATION RATE: raw aggregation
dilutes the dead bias and the unit stays off; canon restores the
bias scale and the unit switches on, which is what uncovers the
payload.  Measured on seed 0.

  aggregate bias of unit 0:  raw   -2.0794   canon   -0.0390
  activation rate of unit 0: raw     0.077   canon     0.486

 payload mag    undef x    M4-only x   own max|df|
----------------------------------------------------
           1     0.9998         7.42       0.0e+00
          10     0.9998       547.58       0.0e+00
         100     1.2616     54544.08       0.0e+00
        1000    40.7082   5453093.89       0.0e+00

Undefended damage is flat -- the raw average keeps the unit off --
while M4 alone grows with the magnitude the adversary picks.  So the
honest statement is not that M4 misses this move but that M4 used
ALONE turns it into a live one.  A19.3 puts M1-M3 back.
clean-vs-killed baseline: 1.0095x (the denominator)

A19.3  the dispersion estimate against the dead-unit payload
==============================================================================

alg:pipeline weights by inverse across-round dispersion with a
floor.  The payload is invisible in function space but it is a
large move in PARAMETER space, and the estimator reads parameter
space, so it should catch it.  Pure inverse variance, lam = 1.0.

Contained. The statistics that miss a gauge move do see a dead
unit, because the payload has to move in parameter space to do
anything and the dispersion estimate reads parameter space.  Note
the norm ratio: this payload is also not norm-stealthy, which is a
second independent reason a deployment would catch it.

==============================================================================
A19.4  M2's weight floor against an unbounded payload
==============================================================================

M2 guarantees every client at least (1-lam)/N, which is what
bounds displacement of an honest client (thm:displacement).  The
same floor guarantees the ADVERSARY that weight, and the payload
magnitude is free, so the two directions of M2 conflict here.
inf = the federation diverged, which is the adversary's outcome.

   lam  floor (1-lam)/N   median x   adv weight   diverged
------------------------------------------------------------
  1.00           0.0000     1.0036    1.062e-13       0/3
  0.99           0.0004        inf    2.717e-02       3/3
  0.90           0.0042        inf    2.849e-02       3/3
  0.50           0.0208        inf    3.435e-02       3/3

So the containment in A19.3 is the inverse-variance term's, and
M2's uniform term is what admits the payload.  That is a real
tension in the mechanism set and it belongs in the paper as one:
M2 bounds what a peer frame can do to an honest client and it
cannot also bound what an out-of-Gamma payload does to the
aggregate, because its floor is unconditional.  The pipeline needs
the norm bound of A19.3's last column for this move, which is
exactly the check rem:alternatives declines for gauge moves --
declines because a gauge move is norm-stealthy and this is not.

==============================================================================
A19 conclusion: Gamma is not the full set of function-preserving
maps.  A dead unit's outgoing column is exactly free (max|df| = 0,
not 1e-16) and unreachable within Gamma, and M4 in isolation
amplifies it to 5453094x where the raw average sits at 40.71x.
Inverse-variance weighting returns it to a median 1.00x at adversary
weight 1e-13, and the submission is 18500.0x the honest median norm,
so unlike a gauge move it is not norm-stealthy either.  But M2's
weight floor admits it (A19.4), so the honest claim is that the
pipeline's VARIANCE term contains this move while its ANCHOR term
does not, and the two mechanisms pull in opposite directions on it.
==============================================================================
